# Монитор очереди в школы

Личный инструмент автоматизации: следит за позициями в очереди на зачисление в школы на портале Минобраза Свердловской области и отправляет обновления в Telegram.

## Что делает

- Парсит страницу с очередью через headless-браузер Chromium (Playwright) — страница рендерится внутри iframe через JS, обычный HTTP-запрос не работает
- Отслеживает позиции конкретных заявителей по нескольким школам
- Ведёт историю позиций и показывает изменение относительно первого замера
- При каждом запуске отправляет сообщение в Telegram с текущим состоянием очереди
- Рассчитан на запуск по расписанию (Task Scheduler, cron и т.д.)

## Стек

- **Python 3**
- **Playwright** — управление браузером
- **Requests** — отправка сообщений через Telegram Bot API
- **JSON** — хранение состояния между запусками

## Структура проекта

```
bot_monitor.py      # основной скрипт — парсинг → формат → отправка → выход
telegram_debug.py   # утилита: выводит chat_id чатов, где есть бот (для первичной настройки)
state.json          # история позиций (создаётся автоматически при первом запуске)
.env                # токены (BOT_TOKEN, CHAT_ID) — не коммитить
requirements.txt
docker-compose.yml  # опциональный запуск в контейнере
```

## Установка

### 1. Зависимости

```bash
pip install -r requirements.txt
playwright install chromium
```

### 2. Создать `.env`

```env
BOT_TOKEN=токен_телеграм_бота
CHAT_ID=id_чата
```

Если не знаешь `CHAT_ID` — запусти `telegram_debug.py`, он выведет все доступные чаты.

### 3. Настроить цели

В `bot_monitor.py` обновить `TARGETS` (ID заявителей) и `SCHOOLS` (названия школ и лимиты мест) под свой случай.

### 4. Запуск

```bash
python bot_monitor.py
```

Скрипт отрабатывает один раз и завершается. Повторные запуски — через планировщик.

## Расписание через Task Scheduler (Windows)

- **Программа:** `d:\school\venv\Scripts\python.exe`
- **Аргументы:** `bot_monitor.py`
- **Рабочая папка:** `d:\school`
- **Триггер:** повтор каждые 2 часа
